# 🚗 Caronaê - Desafio Técnico

Interface web desenvolvida como solução para o desafio técnico de admissão de novos desenvolvedores para o projeto de extensão **Caronaê** (UFRJ).

---

## 📌 Sobre o Projeto
O **Caronaê** é uma iniciativa universitária que visa conectar a comunidade acadêmica para o compartilhamento de caronas. 

Este repositório contém a implementação do desafio Front-end (edição 2024.2), cujo objetivo principal foi construir uma aplicação capaz de consumir uma API REST externa para exibir informações dinâmicas sobre as caronas disponíveis no sistema. O desenvolvimento focou em boas práticas de versionamento (Git), organização de código e componentização.

## 🎯 Funcionalidades Implementadas
Atendendo aos requisitos do escopo do desafio, a aplicação possui:
* **Catálogo de Caronas:** Uma página inicial (Dashboard) responsável por listar todas as caronas disponíveis retornadas pela API.
* **Detalhes da Carona:** Uma página de detalhes dinâmicos que exibe informações específicas e aprofundadas sobre uma carona selecionada pelo usuário.
* 
## 🛠️ Tecnologias e Ferramentas

* **Framework/Biblioteca:** React.js
* **Consumo de API:** Axios
* **Roteamento:** React Router Dom
* **Testes:** Jest

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de iniciar, certifique-se de que tem as seguintes ferramentas instaladas:
*   npm: gerenciador de pacotes do Node.js
*   Node.js (Recomendado utilizar a versão v20.11.0 para evitar incompatibilidades)

### 1. Executando a aplicação
1. **Clone o repositório:**
 ```bash
 git clone [https://github.com/DudaLeal/desafio-tecnico-caronae-2024-2.git](https://github.com/DudaLeal/desafio-tecnico-caronae-2024-2.git)
 ```

2. Navegue até a pasta:
```bash
   cd caronae-frontend
```

3. Instale as dependências:

```bash
   npm install
```

4. Inicie o servidor frontend:

```bash
   npm start
```

A aplicação estará disponível em `http://localhost:3000`.

### 2. Rodando testes

Inicie os testes:

```bash
   npm test
```
